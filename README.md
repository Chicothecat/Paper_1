This study evaluates model performance across four benchmark network intrusion detection datasets, covering diverse traffic patterns from enterprise environments, IoT/IIoT ecosystems, and botnet activities.

| Dataset | Format / Version | Description | Source |
| :--- | :--- | :--- | :--- |
| **NF-CSE-CIC-IDS2018-v2** | NetFlow v9 | Enterprise network traffic with realistic background traffic and contemporary cyber attacks | [Kaggle](https://www.kaggle.com/datasets/dhoogla/nfcsecicids2018v2) |
| **NF-ToN-IoT-v2** | NetFlow v9 | Telemetry and network traces from large-scale IoT/IIoT testbeds | [Kaggle](https://www.kaggle.com/datasets/dhoogla/nftoniotv2) |
| **NF-BoT-IoT-v2** | NetFlow v9 | Large-scale botnet traffic mixed with normal IoT communication patterns | [Kaggle](https://www.kaggle.com/datasets/dhoogla/nfbotiotv2) |
| **CTU-13** | Mixed (PCAP / NetFlow / BiArgus) | 13 real-world botnet scenarios captured by the Stratosphere Laboratory | [Stratosphere IPS](https://www.stratosphereips.org/datasets-ctu13) |
